Wild Kids - Computers is a free, offline app where children aged 3 to 12 learn to use a computer by playing and painting.

**Install:** pick the file for your system below. The [install steps](https://github.com/NicL9923/wild-kids-computers#install) cover each one, including how to remove the app.

| System                   | File                     |
| ------------------------ | ------------------------ |
| Omarchy, Arch Linux      | `.pkg.tar.zst`           |
| Debian, Ubuntu           | `.deb`                   |
| Fedora                   | `.rpm`                   |
| Other Linux              | `.AppImage` or `.tar.gz` |
| macOS with Apple silicon | `.dmg`                   |
| Windows                  | `.exe`                   |

The installers are not signed. macOS and Windows warn before the first start; the install steps say what to choose. `SHA256SUMS` lists the checksum of every file.
